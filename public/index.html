업무를 마치는 작은 습관중요한 변경 후에는 JSON 백업 파일을 기관 지침에 맞는 안전한 위치에 보관하세요.

데이터는 어디에 저장되나요?

연수 운영 데이터는 사용자의 해당 브라우저 IndexedDB에 저장됩니다. 다운로드한 HTML 파일 자체에 저장되는 것은 아닙니다. 사이트 데이터 삭제나 브라우저 초기화로 데이터가 사라질 수 있으니 별도 백업을 보관하세요.

다른 PC나 브라우저에서도 이어서 쓸 수 있나요?

다른 PC·브라우저와 자동 동기화되지 않습니다. 전체 JSON 백업 파일을 안전하게 옮긴 뒤, 사용할 환경에서 복원해 주세요. 이동 전후 데이터가 맞는지 먼저 확인하세요.

새 버전은 기존 파일 위에 저장하면 되나요?

파일 자체를 덮어쓰기보다 버전별 별도 보관을 권장합니다. 업데이트 전 전체 JSON 백업을 만들고 새 버전에서 데이터와 기능을 확인한 후 실제 운영에 사용하세요.

실제 교육생 정보를 입력해도 되나요?

기관 보안지침과 개인정보 처리기준에 따라 사용 여부와 입력 범위를 먼저 확인하세요. 공용 PC 사용에 주의하고, 백업 파일에도 개인정보가 포함될 수 있으므로 접근과 보관을 관리해 주세요.

이 페이지의 설문과 연수 운영 데이터는 같은가요?

서로 다릅니다. 이 페이지에서 제출하는 경험 설문만 서비스 개선을 위해 서버의 비공개 저장소로 전송됩니다. 로컬 연수 운영 데이터는 이 설문으로 전송되지 않습니다.
